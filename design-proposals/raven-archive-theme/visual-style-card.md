# LUMEN / RAVEN ARCHIVE 视觉风格卡

状态：`locked · default standard`
版本：`A2.2 · 银盐鸦影 / THEME STANDARD`

## 风格必须帮助产品做到什么

让大量色彩复杂的素材在一个安静、可信、近似摄影暗房工作台的界面中被整理；界面提供明确操作反馈，但不与素材争夺注意力。

## 决策层级

- `U`：正式图标使用 `build/raven-icon-source.svg` 的乌鸦照片轮廓；不得重新加入蓝色眼睛、字母或赛博符号。
- `A`：石墨黑工作区、银灰结构层、暗房红操作信号，以及“档案柜 → 接触印样 → 检视记录 → 看片台”的工作流结构作为当前实现基础。
- `D`：暗房红仅用于选择、主操作、进度和安全灯状态；评分使用旧相纸暖银。银盐机制不得覆盖素材原图。
- `V`：安全灯红强度、颗粒强度、动效时长和工作区信息密度可在校准中微调。

## 不可变 DNA

1. 黑色主体：主要工作区保持近黑，不使用偏蓝的大面积底色。
2. 银灰层级：边框和正文来自图标背景的中性银灰，不做发光描边。
3. 稀有红色：红色必须是信号，不是装饰背景。
4. 摄影材料感：允许极轻颗粒、相纸边框和暗房曝光线；禁止扫描线、RGB 撕裂和像素阶梯角。
5. 素材优先：缩略图保持真实色彩，界面 hover 只做轻微对比度与饱和度收敛。

## 组件语法

- 品牌区：正式乌鸦图标装入带齿孔的 35mm 底片框；高字距 LUMEN、片号与 `RAVEN PHOTOGRAPHIC INDEX` 组成档案铭牌。
- 导航：作为档案柜索引；活动项用登记线和低亮度安全灯染色，不使用亮色面板。
- 工作区抬头：每个视图都是一张 `CONTACT SHEET`，显示档案号、张数、选片数、片种与处理日期。
- 筛选台：转译为放大机控制台；按钮对应片种、色彩、评级、曝光日期和排序，顶部使用离散刻度而非装饰性扫描线。
- 素材卡：直角工作印样、相框压边、帧号和片种尾标；图像保持原色，界面仅承担归档关系。
- 详情栏：独立的 `INSPECTION RECORD`，预览是带边界的工作样片，元数据采用检视记录表的点线分隔。
- 悬停预览：挂载在页面根层，始终限制在素材墙可视边界内；首末列自动左右换边，底部素材向上收拢，不侵入顶栏、档案栏或检视记录。
- 白板：定义为 `LIGHT TABLE` 看片台，空态停留在屏幕坐标层，不受画布视口偏移影响。
- 弹窗：暗房控制记录页；石墨纸面、发丝边框、页码式标记和安全灯主操作。

## 比例与拥挤控制

- 顶部批次抬头压缩为 `54px`，只保留当前视图、素材总数、选片数与真实处理状态，不展示伪片种或装饰日期。
- 左侧档案柜基准宽度 `220px`，右侧检视记录基准宽度 `252px`；中等窗口分别收敛到 `208px / 232px`。
- 筛选台将“导入、搜索、AI 处理、视图切换”列为常驻高频动作；中等宽度优先压缩按钮间距和输入框，不允许把这些动作推出可视区。
- AI 搜索开关作为输入框右侧独立方键，不叠在搜索说明文字上。
- 侧栏文件夹、智能文件夹与标签共用一条纵向索引滚动；禁止分区嵌套滚动和横向滚动条。

## 动效语法

- `走片 / film advance`：视图工具台进入时横向移动 14px 后归位，表达切换批次，不持续循环。
- `显影 / print develop`：新进入视口的工作印样从低亮度、高反差、轻微下沉状态在 440ms 内显现。
- `曝光 / exposure sweep`：素材刚被选中时只有一次短促红色光带扫过，随后完全消失。
- `对焦 / focus settle`：详情记录切换素材时从 3px 模糊与低亮度快速归焦，不改动图片本身。
- `安全灯 / safelight`：只在真实处理中缓慢呼吸；就绪态保持静止。
- `相纸抬起 / paper lift`：弹窗从轻微下沉和低亮度进入，避免通用缩放弹跳。
- 所有动效响应 `prefers-reduced-motion`；禁止胶片刮痕乱闪、相机抖动、无限走片与 RGB 故障。

## 禁止项

- 大面积电蓝、霓虹青或蓝色外发光。
- 像素切角、8-bit 装饰、RGB 通道撕裂。
- 为了“乌鸦感”加入羽毛纹理、爪印或哥特字体。
- 在素材缩略图上覆盖可见颗粒或全局降饱和滤镜。

## 校准闸门

1. 首页：彩色素材仍是视觉第一层；档案编号、批次抬头和安全灯能说明工作状态，而非纯装饰。
2. 素材墙：帧号、片种、选中曝光与 hover 抬升在密集瀑布流中仍可辨识。
3. 详情栏：空态、单选、多选均保持检视记录身份，切换时对焦动效不拖慢操作。
4. 白板：看片台空态固定居中，深灰画布、工具与素材仍能清晰分层。
5. 弹窗：主次操作、危险操作和文字可读性不混淆；动效不依赖动画才能理解。
6. 已由用户指定为默认主题与视觉标准；后续修改必须升版本并同时回归像素故障主题。
