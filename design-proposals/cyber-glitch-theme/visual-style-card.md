# LUMEN 第三主题视觉风格卡

状态：`calibrating`  
版本：`PX–02R · 信号故障 / CYBER SIGNAL TERMINAL`

## 设计定位

「信号故障」保留大改前像素主题最有辨识度的赛博终端基因，但把旧版的全屏网格、泛滥切角、持续闪烁和素材滤镜收敛为一套可长期工作的主动信号台。它与 PX–03.1 的“伪档案系统”分家：PX–03.1 是冷静、制度化、年代错位的档案终端；PX–02R 是锐利、即时、以通道和校验反馈驱动的数字工作台。

## U / A / D / V

- `U`：作为设置中的第三套完整主题；来源是大改前偏赛博的像素故障版本，但必须优化后独立存在，不能覆盖或倒退 PX–03.1。
- `A`：海军黑工作面、磷光青活动通道、洋红校验/异常位、4px 像素切角、节点总线和离散反馈构成当前基线。
- `D`：主题名暂定「信号故障」，代码 `PX–02R`；素材库使用 SIGNAL MATRIX，详情栏使用 TRACE PANEL，白板使用 NODE CANVAS / BUFFER RACK。
- `V`：后续可校准青色亮度、网格密度、切角尺寸与动效时长；不得改变功能拓扑、素材颜色或操作路径。

## 视觉 DNA

1. **空间**：深海军黑而非纯黑，局部 32px 信号网格只服务工作区定位；禁止把全屏背景做成发光赛博墙。
2. **颜色**：青色只表达可操作、选中、在线和活动通道；洋红只表达校验、AI、告警和第二状态；普通文字保持冷灰白。
3. **轮廓**：卡片、弹窗和焦点框使用克制的 4—5px 像素切角；普通文本行和所有小按钮不逐个切角。
4. **排版**：Cascadia Mono / JetBrains Mono 为工作字体，中文回落 Microsoft YaHei UI；标题仍服从原布局比例，不用夸张霓虹展示字。
5. **图形**：节点总线、短刻度、通道槽、校验块和坐标线必须对应真实栏目、真实状态或真实数量；不生成随机遥测。
6. **素材保护**：缩略图、预览、详情图、白板素材始终 `filter:none`；扫描线、噪声、RGB 偏移不得进入内容层。

## 页面语言

| 区域 | PX–02R 语义 | 视觉职责 |
| --- | --- | --- |
| 品牌/侧栏 | `SIGNAL / 02`、`LOCAL SIGNAL MATRIX`、`SIGNAL BUS · ONLINE` | 建立工作台身份；青色总线只在导航结构中出现 |
| 主抬头 | `SIGNAL MATRIX`、`BUS / FORMAT / LINK`、`BUF` | 绑定当前档案、媒体类型、连接状态和选中数量 |
| 工具栏 | `I/O FILTER BUS` | 高频工具保持原位置；青色为主动作，洋红为 AI/校验 |
| 素材卡 | 短哈希、青洋红登记位、4px 切角 | 区分信号记录，但不覆盖素材图像 |
| 详情栏 | `TRACE PANEL`、`BUFFER VIEW`、`CODEC / RASTER / BYTES` | 绑定当前素材真实元数据 |
| 设置 | `CONTROL ROOM`、`SIGNAL CONFIG` | 偏好模块作为补丁舱，三主题卡并列且长内容独立滚动 |
| 白板 | `NODE CANVAS`、`FILE I/O`、`BUFFER RACK` | 画布、工具与参考架形成同一信号工作流 |

## 动效

- 面板、菜单、卡片进入使用 120—180ms `steps(2—3, end)` 离散锁定，不使用无限抖动。
- 状态发生变化时允许一次短促校验闪；READY/ONLINE 静止。
- 素材悬停只增强边线和 1px 对位，不改变图片色相、对比度或清晰度。
- `prefers-reduced-motion` 下关闭位移、闪烁和分阶过渡，仅保留即时状态切换。

## 禁止项

- 全屏高亮网格、持续 CRT 扫描线、常驻故障抖动。
- 所有按钮、卡片、输入框都做切角或发光。
- 对素材图像做青色化、灰阶、RGB 色偏、噪点或扫描线覆盖。
- 随机十六进制、虚假带宽或无来源的系统状态。
- 为主题新建独立导航、启动页、底部任务栏或与 LUMEN 功能无关的模式轨道。
- 与 PX–03.1 共用 `MASTER INDEX / INDEX LOG / ARCHIVE CANVAS` 的制度化档案语义。

## 校准闸门

1. 首页、详情、设置、白板四张真实截图可清楚辨认 PX–02R，且不依赖素材内容判断主题。
2. 1280—1366px 下高频工具完整，非关键遥测自动隐藏；侧栏、素材墙、设置正文保持可滚动。
3. 三主题往返切换、刷新持久化、非法值回落银盐鸦影。
4. 素材缩略图、详情预览、悬停预览和白板图片均无滤镜污染。
5. 白板拖放、平移、双侧栏收起、外观抽屉、文字/绘图工具行为不因主题改变。
6. 类型检查、生产构建、主题/设置/顶栏/菜单/白板/更新弹窗回归全部通过后，才可由 `calibrating` 进入候选锁定。
