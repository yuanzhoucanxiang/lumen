# LUMEN / PIXEL GLITCH 视觉风格卡

状态：`calibrating`
版本：`PX2 · 像素故障 / SIGNAL DISCIPLINE`

## 风格必须帮助产品做到什么

让高频整理与检索操作呈现为可读的视觉终端：反馈锐利、状态明确、密度紧凑，但故障语言只能说明“数据发生变化”，不能持续干扰用户观察素材。

## 决策层级

- `U`：与银盐鸦影共同进入设置页主题功能；必须保留正式乌鸦图标与全部产品能力。
- `A`：深海军黑终端、磷光青主信号、洋红校验位、像素切角、离散数据锁定动效构成当前主题基线。
- `D`：青色承担选择与主操作；洋红只作校验位和瞬时故障副通道，不作为大面积背景。
- `V`：网格强度、切角尺寸、单次故障位移与终端字体密度可继续校准。

## 不可变 DNA

1. 数字终端：界面采用等宽数据字体、低亮网格与清晰节点编号。
2. 离散故障：故障只在切换、选择、悬停锁定和提示入场时短促发生；禁止持续抖动。
3. 双信号位：磷光青是主通道，洋红只提供极少量错位校验。
4. 像素轮廓：卡片、弹窗、主按钮使用 6–12px 切角，不使用圆润相纸语法。
5. 素材无损：扫描线、RGB 色偏和网格不得覆盖素材原图；图像 hover 最多发生 1px、160ms 的锁定反馈。

## 组件语法

- 品牌区：乌鸦图标进入切角信号框；`SIGNAL / 02`、`LUMEN` 与 `VISUAL MEMORY TERMINAL` 形成节点铭牌。
- 导航：活动项由左侧 3px 青色锁定线、低亮网格与右侧洋红校验位共同标识。
- 工作区抬头：`ASSET MATRIX`、节点号、素材节点数与 `ONLINE / SYNCING` 组成真实状态头。
- 筛选台：定义为 `I/O FILTER BUS`；主操作与查询保持可见，按钮轮廓直角、紧凑。
- 素材卡：像素切角、节点号与片种尾标；图片本身不叠加扫描线或长期色偏。
- 详情栏：`TRACE PANEL` 使用缓冲区视图和结构化数据行，不沿用相纸检视语法。
- 白板：定义为 `NODE CANVAS`，空态像一个待接入的视觉节点。
- 弹窗：信号配置面板，网格底、切角轮廓和硬阴影；主题选择支持即时预览。

## 动效语法

- `panel lock`：面板以 3–4 阶离散裁切入场，180–220ms 后稳定。
- `data scan`：选中卡片时一次横向数据扫描，260ms 后完全消失。
- `image lock`：hover 时图片做不超过 1px 的三帧定位校验，160ms 后回到原位。
- `signal pulse`：只在真实同步/处理中使用两帧脉冲；就绪态静止。
- `reticle`：详情空态准星允许低频、分阶旋转；不得在素材图上出现。
- 所有动效响应 `prefers-reduced-motion`。

## 禁止项

- 全屏扫描线、素材缩略图 RGB 分色、持续闪烁或随机抖动。
- 大面积高饱和青/洋红底色。
- 为追求“赛博”牺牲中文可读性或把正文压到 10px 以下。
- 用 glitch 掩盖加载、错误或选择状态，状态必须有稳定文字与结构信号。

## 校准闸门

1. 首页、详情、设置、白板四个压力页面保持同一终端语法。
2. 工具栏高频动作在中等窗口下完整可见。
3. 素材库与侧栏都能独立纵向滚动，无横向溢出。
4. 悬停预览留在素材墙边界内，切角与阴影不影响定位。
5. 刷新应用后主题保持，清除用户设置后回到银盐鸦影。
6. 通过用户实际试用确认后再将状态改为 `locked`。
