# LUMEN / PIXEL GLITCH 视觉风格卡

状态：`calibrating`
版本：`PX3.1 · 像素故障 / RETRO SCI-FI TERMINAL · PSEUDO-ARCHIVE SYSTEM`

## 风格目标

用户硬锁定义：**复古科幻终端美学 / 伪档案系统风**。LUMEN 不只是变成一台黑白工作站，而是伪装成一个具有机构身份、权限层级和档案仪式的虚构终端系统；旧式点阵、早期桌面窗口和年代错位负责科幻媒介感，目录、编号、验证、记录与日志负责伪档案叙事。所谓“故障”来自不同年代媒介层的冲突，而不是霓虹、网格或持续抖动。

## 参考拆解

- 参考 1 决定启动与品牌语法：近黑背景、极细白线、稀疏编号和大量留白。
- 参考 2 决定档案桌面的媒介语法：黑白点阵、极小的蓝红状态位和工作站式信息分层；不继承其中央索引与底部系统栏布局。
- 参考 3 决定信息窗口语法：低密度终端数据、传统钴蓝标题条和面板式层级。
- 参考 4 决定处理反馈：点阵只用于载入、索引和系统图形，不覆盖用户素材。

补充项目研究不以复刻截图为目标，而是提取五种可复用机制：NASA 1976 视觉规范提供机构网格、规则线和留白纪律；《Alien: Isolation》提供“用户功能层清晰、设备媒介层陈旧”的双层界面原则；《Observation》提供摄像机、节点、链路与系统状态构成的可信遥测视角；《SIGNALIS》提供固定信息槽、诊断舱和高对比模块化分区；《Control / FBC Firebreak》提供在既有导航蓝图内叠加档案机构身份的方法。完整来源、转译与禁用项见 `reference-research.md`。

因此 PX–03.1 的合成公式锁为：**机构网格 × 功能/设备双层界面 × 真实状态遥测 × 模块化信息舱 × 伪机构档案叙事**。装饰图形只有在承载真实数据、解释系统状态或强化信息层级时才允许出现。

## 决策层级

- `U`：主题定义为「复古科幻终端美学 / 伪档案系统风」；作为设置中的第二套完整主题，保留正式乌鸦图标、全部产品能力和素材原貌；依托 LUMEN 原有布局做主题化改变，不照搬参考图的页面结构。
- `A`：近黑档案工作站、灰白细线、黑白点阵、早期桌面层级、钴蓝与档案红状态位构成 PX–03.1 当前基线。
- `D`：索引状态复用原有顶栏、侧栏和检视栏呈现；素材图像保持彩色，点阵与失真只进入系统反馈。
- `V`：微缩数据字号、蓝红占比、点阵密度和既有状态信息密度仍可根据实际试用校准。

## 不可变 DNA

1. 黑白档案：约 80% 近黑负空间、17% 灰白结构信息、3% 蓝红状态位。
2. 早期工作站：直角薄框、硬阴影、分层标题条和清晰窗口焦点；不复刻具体操作系统，也不新增系统级任务栏。
3. 点阵有职责：只用于索引、加载、系统插图和瞬时校准，绝不长期压在素材上。
4. 状态优先：蓝色表示活动通道，红色表示记录点或异常；主操作仍以灰白为主。
5. 素材无损：缩略图、预览和白板原图默认 `filter: none`；悬停校准结束后必须恢复原图。
6. 拓扑继承：素材库继续使用左侧导航、中央顶栏/工具栏/素材墙、右侧检视栏；白板继续使用既有独立工作区。主题可调整比例与内部层级，不得替换产品导航模型。

## 组件语法

- 品牌区：乌鸦图标进入灰白档案框，`INDEX / 03` 与 `LOCAL VISUAL INDEX` 形成登记铭牌。
- 导航：活动项使用灰白轮廓、钴蓝右边线和红色记录点；非活动区尽量保持空。
- 工作区抬头：`MASTER INDEX`、档案号、记录数量与稳定的 READY 状态组成索引台。
- 抬头遥测：`CHANNEL / MEDIA / ACCESS` 必须分别来自当前档案号、真实媒体类型数量和当前视图权限；中等宽度下整体收起，不与高频工具争夺空间。
- 筛选台：黑色直角控件；导入是灰白主按钮，查询与筛选不使用大面积品牌色。
- 素材卡：平面薄框、左上短索引码、底部记录条；素材保持真实色彩。
- 详情栏：`INDEX LOG` 使用登记视图、静态准星和结构化信息，不做发光监视器。
- 详情栏：素材选中后增加 `TYPE / FRAME / SIZE` 三槽登记摘要；全部使用当前素材元数据，禁止随机设备码。
- 设置：使用 `00—06` 机构模块网格、编号边栏和连续规则线组织偏好项；钴蓝只作为当前选择的套准线，不铺成彩色卡片。
- 白板：`ARCHIVE CANVAS` 与 `REFERENCE TRAY` 构成独立工作区；工具、素材架和画布使用同一档案语法。
- 状态信息：沿用原有顶栏、侧栏和检视栏承载索引、记录与选择状态，不新增常驻任务栏。

## 布局继承边界

- 保留：左侧素材库导航、中央素材工作区、顶栏与筛选工具、右侧检视栏，以及白板模式已有的素材库列表与参考素材架。
- 允许改变：栏宽、顶栏高度、留白密度、标题与数据比例、分隔线、控件组合方式、侧栏收起形态、信息层级和响应式压缩策略。
- 禁止照搬：独立身份启动页、环形目录导航、右侧 00–03 模式轨道、替代检视栏的漂浮旧窗口、常驻底部系统任务栏。
- 参考图中的轨道、节点、旧窗口和点阵球体，只能转译为局部状态图形、空态、载入反馈或弹窗层级，不能接管产品主布局。

## 动效语法

- `panel register`：面板以 3 阶、150–170ms 的小幅位移登记入场，结束后完全静止。
- `record in`：卡片以短促透明度/对比度校准出现，不进入全灰阶段，170ms 后恢复素材原貌。
- `image register`：悬停时最多 1px、130ms 的定位校准，结束后 `filter: none`。
- `index scan`：只在真实载入或索引时出现一次横向扫描；READY 状态不动。
- `window in`：弹窗使用 150ms、三阶硬位移，不做弹簧或漂浮。
- 全部动效响应 `prefers-reduced-motion`；不得有无期限运行的装饰动画。

## PX–03.1 深化校准

- 登记痕迹：只在当前目录、选中素材、窗口标题和检视记录中出现；空闲区域保持黑场，不铺满装饰纹理。
- 机械锁定：键盘焦点和真实选中动作使用 120ms、两阶硬位移；结束后不保留发光或抖动。
- 卡片套准：选中素材增加四角裁切标记与底部钴蓝通道线，标记属于卡片框架，不改变素材图像滤镜。
- 窗口焦点：菜单与弹窗使用双层硬边、偏移阴影和灰白/钴蓝/档案红短登记带，避免大面积蓝色标题面。
- 点阵约束：点阵被压缩为目录索引轨和检视栏校准块；红色仍只表达记录/异常，不承担普通 hover。
- 系统图形：允许使用点阵球、同心套准环、十字准星、测量刻度、记录表格、节点连线和编号槽，但每类必须分配明确位置——检视空态承载校准图与表格，抬头负空间承载刻度，白板空态承载节点图，主题预览承载微缩系统结构；禁止覆盖素材、占据导航层或演变成独立页面结构。
- 真实遥测：顶栏 `CHANNEL / MEDIA / ACCESS`、检视栏 `TYPE / FRAME / SIZE` 必须直接绑定当前视图和素材数据。无法取得真实值时宁可省略，不以伪随机字符串填充“科幻感”。
- 机构网格：设置页以 72px 基准模块和 `00—06` 编号形成跨章节连续骨架；网格负责对齐、分组与扫描路径，不作为全屏背景纹理。

### 白板 / Archive Plotting Table

- 白板不是素材库边缘的一块通用深色画布，而是 PX–03.1 内部独立成立的「档案制图台」；仍保留素材库列表、参考素材架、原工具和无限画布的既有拓扑。
- 顶部记录头按 `ARCHIVE CANVAS / FILE I/O / SCALE` 分责：白板名称是当前记录牌，文件导入导出属于 I/O 通道，缩放是独立标尺，不再把所有按钮混成一排。
- 绘图工具按 `DRAW / HISTORY / VIEW` 三个仪器通道编组。活动工具使用灰白锁定框与钴蓝通道线；非活动工具保持低对比，不以大色块模拟普通软件选中态。
- 画布由三层构成：可随视口移动的细点阵、固定的 160px 主坐标分区、边缘套准角与节点关系图。它们只位于画布底层，不覆盖白板素材，也不改变用户选择的画布底色。
- 参考素材架是接入制图台的「源记录槽」：标题、搜索、拖放说明和素材卡共同使用刻度、记录边线与裁切角；素材缩略图仍保持原色和完整可读。
- 外观抽屉定义为 `DISPLAY CALIBRATION / BG-GRID`，继续向下推开画布而非弹出覆盖；色板、网格与密度属于显示校准，不伪装成新的导航层。
- 窄屏时优先隐藏装饰刻度与微型通道名，保留白板选择、文件操作、缩放、工具和退出动作；美术层不得制造新的功能溢出。

## 禁止项

- 青色霓虹主色、赛博网格、像素切角泛滥、全屏扫描线。
- 素材缩略图持续灰阶、RGB 分色、噪声覆盖或随机抖动。
- 为模拟复古系统而牺牲中文可读性、键盘焦点或关键操作面积。
- 蓝红色成为大面积装饰底色；它们只能表达活动、记录、错误和窗口层级。
- 把参考图中的具体品牌、文案、角色或布局逐字照抄。
- 为体现主题而重建一套与 LUMEN 原功能无关的导航或页面拓扑。

## 校准闸门

1. 首页、详情、设置、白板四个压力页面保持同一档案工作站语法。
2. 工具栏高频动作在中等窗口下完整可见；主题不得新增挤压主高度链的常驻区域。
3. 素材库、侧栏、参考素材架和设置正文均能独立滚动，无横向溢出。
4. 悬停预览留在素材墙边界内，素材最终滤镜为 `none`。
5. 白板独立模式、双侧收起、拖放、平移和外观抽屉继续通过既有回归。
6. 刷新后主题保持，清除设置回到银盐鸦影；两主题均不新增脱离原布局的常驻系统栏。
7. 像素主题与银盐主题共享同一功能拓扑；切换主题后导航位置、工作区关系和操作路径不发生重构。
8. 通过用户实际试用确认后，才将状态从 `calibrating` 改为 `locked`。
9. 所有新增遥测字段均可追溯到当前状态或素材元数据；禁止无业务来源的装饰性数值。
10. 1280—1366px 窗口下抬头遥测自动退场，导入、搜索、筛选、AI 处理、视图和缩放仍完整可操作。
