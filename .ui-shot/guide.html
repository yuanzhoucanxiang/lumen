LUMEN 拾光档案馆 · 安装使用说明

一个类 Eagle 的本地素材管理工具：收集、整理、检索你的图片/视频/字体/PSD 素材。
数据全部存在你自己电脑上，无需注册、无需联网（联网仅用于自动更新）。

一、下载与安装

  1. 打开下载页，下载最新的 Lumen-x.x.x-setup.exe（约 147MB）：

https://github.com/yuanzhoucanxiang/shiguang-materials/releases/latest

  1. 双击安装包。如果 Windows 弹出蓝色警告「已阻止启动无法识别的应用」：

点 「更多信息」→「仍要运行」（软件没有购买代码签名证书，属正常现象，放心安装）。

  1. 安装完成，桌面会出现 LUMEN 图标，双击即用。

二、第一次使用

  • 首次启动会自动创建素材库，位置在 文档\EagleLike.library（素材都存这里，别手动改里面的文件）。
  • 导入素材的六种方式：
  1. 直接把文件/文件夹拖进窗口
  2. 左上角蓝色「导入」按钮
  3. 复制图片后按 Ctrl+V 粘贴
  4. 复制图片网址后按 Ctrl+V 直接抓取网页图片入库（一次可粘多条）
  5. 用浏览器扩展剪藏网页图片（见第六节）
  6. 顶栏「截图」按钮做区域截图：窗口自动隐藏，拖框选取屏幕任意区域，松开即入库（Esc 取消）

四、整理素材

  • 框选：在图库空白处按住拖拽，框住多张素材一次选中（Ctrl/Shift 拖拽为追加模式）
  • 评分：悬停卡片点星星，或选中后按键盘 1–5
  • 打标签：选中图片，在右侧详情面板添加；多选可批量打标签/批量评分
  • 文件夹：侧栏右键 → 新建文件夹/子文件夹，把图拖进去即可（可多选批量拖）
  • 调整文件夹层级：按住文件夹行拖到另一个文件夹上，它就变成对方的子级；拖拽时列表下方会出现

「拖到此处移出为顶层」的虚线槽位，拖过去即放回顶层。不能把文件夹拖进自己的子文件夹（会给出提示），

也不能拖进智能文件夹

  • 智能文件夹：按条件自动聚合（如「4星以上 + 横图 + 近30天」），条件随时可改
  • 标签分组与颜色：右键标签可设颜色、移动到分组，让标签区井井有条
  • 批注/裁剪：右键图片 →「批注 / 裁剪」（画笔/矩形/箭头/文字/裁剪，15 步撤销）
  • 回收站：删除先进回收站，可恢复；Ctrl+Z 撤销删除；30 天前内容自动清理
  • 导出：右键 →「导出到文件夹…」或「打包为 ZIP…」
  • 拖拽导出：按住 Alt 把图片直接拖到资源管理器、聊天窗口或 PS 等其他程序（可多选，默认不带 Alt 的拖拽用于白板/文件夹内部整理）
  • 批量重命名：选中多个素材，右键「批量重命名…」，模板支持 {原名}、{序号}、{日期}，扩展名自动保留
  • 备份与恢复：设置 →「备份」可查看数据库快照（保留 3 代）并一键恢复，恢复前自动保存当前库现场，防误操作
  • AI 智能处理：设置 →「AI 智能处理」填 Base URL / 模型 / API Key（支持智谱、通义、Ollama 等），选中素材后一键批量改名+打标签，还可用自然语言语义搜图

五、白板工作台

视觉化整理参考：做情绪板、分镜参考，或把素材组织成画面关系。

  • 上板：把素材卡片拖进画布，或点卡片「发送到白板」；图片按原始比例落位（长边封顶 1280px、不放大），大图一开始就是清晰原图。
  • 导航：空格+拖动平移；滚轮缩放；F 或双击空白适配全部；0 或顶栏 1:1 按钮回到实际大小。白板会记住上次的缩放与位置，重开自动恢复。
  • 多选与整理：框选或 Ctrl 点选多个后——对齐六向（左/水平居中/右、顶/垂直居中/底）、等距分布、网格/横向/纵向排列、成组（Ctrl+G，点一个就选一组；Ctrl+Shift+G 解组）、图层置顶/置底/上移/下移（Ctrl+]、Ctrl+[，加 Shift 为置顶/置底）。
  • 拖动吸附：拖动元素时会自动吸附到邻近元素的边·中心线和你画的参考线上（吸附线会显示出来）；需要精确错位时按住 Alt 拖动临时关闭吸附；按住 Shift 拖角等比缩放不变形。
  • 锁定：右键「锁定」（Ctrl+L）后该元素不会被拖动、缩放或误删，左上角有锁标记；仍可选中它以便随时解锁。
  • 浮动置顶：点「白板浮动置顶」把当前白板做成独立小窗贴在屏幕最上层（参考作画时放旁边）；标题条可拖，「最小化」折叠成标题条窄条，「展开」还原，「归位」贴回屏幕右上角；重开保持位置、尺寸与折叠状态。
  • 工具与交付：顶栏可选手绘/箭头/形状/文字；右键可改透明度、图片水平/垂直翻转；导出 .lumenboard（可继续编辑，含锁定与成组关系）、SVG（矢量交付）或 PNG（2 倍超采样位图）。
  • 大画布：上千元素的白板只渲染视口内的部分，平移缩放不掉帧；放大到 100% 以上才按需加载原图（同屏最多 32 张，优先给屏幕上最大的那些）。

六、浏览器剪藏（LUMEN Clip）

在网页上看到好图，一键收进库里：

  1. 打开 Chrome → 地址栏输入 chrome://extensions → 右上角打开开发者模式
  2. 点「加载已解压的扩展程序」，选择发给您的 browser-extension 文件夹
  3. 保持 LUMEN 应用在运行，然后：
  • 点扩展图标 →「剪藏本页图片」批量收图（可按尺寸/格式过滤）
  • 「区域截图」框选网页局部；「整页长截图」自动滚动拼接
  • 或在图片上右键 → 剪藏图片到 LUMEN

七、自动整理（监控文件夹）

设置（左下角 ⚙）→「监控文件夹」添加目录，支持多个、含子目录。

之后这些文件夹里新出现的图片/视频会自动导入素材库——

配合下载目录使用，下载即入库。

八、Agent 接入（让 AI 助手帮您收图）

LUMEN 在运行时开放了一个仅限本机的 HTTP 接口（端口 45678，浏览器剪藏也走它），

并自带一套「lumen」技能文件——AI 助手（如 ZCode、Claude Code）装上它，

就能把散落在各个文件夹里的生成图片/素材批量收进素材库，自动打标签、归文件夹。

不使用 AI 助手的话，本节可以完全忽略，LUMEN 不会往您的电脑写入任何技能文件。

  • 安装：设置（左下角 ⚙）→「Agent 接入」→ 点「安装技能到本机 Agent」。

技能随 LUMEN 安装包自带，会装到 ~/.agents/skills/lumen（检测到 Claude Code 时同步一份到 ~/.claude/skills/lumen）；

使用其他 AI 工具可点「打开技能文件夹」把里面的文件手动复制过去。LUMEN 更新后可重新安装获取新版技能。

  • 使用：对助手说「帮我把 XX 文件夹里的图整理进 LUMEN」即可。
  • 接口默认复制导入（源文件保留）；重导入同一批文件会自动跳过，且照常补上标签/归档——

助手重复执行也不会漏掉已入库的文件。

  • Agent 导入的素材默认自动归入「Agent 导入」文件夹（助手显式指定文件夹时除外），与您自己的素材分开，不会混淆。
  • 标签、文件夹（支持 A/B 多级）不存在时会自动创建。
  • 助手还可以在生成前先查询图库（避免重复生成）、用试运行预估一批文件的导入规模、把 prompt 等生成信息写进素材备注（之后搜备注就能找到"这张图当时怎么生成的"）、在导入时自动检测与库内现有图片相似的新图防止近重复图淹没图库、按需直接把图送上白板画布，或在后台用 AI 自动打标签（完成后界面会提示）。
  • 若助手提示连不上（端口 45678 无响应），先启动 LUMEN 再试；

若提示 /import 不存在，说明 LUMEN 版本过旧，更新后即可。

九、多个素材库

侧栏底部可切换/新建素材库（比如「工作图库」和「个人图库」分开）。

每个库是一个独立文件夹，也可以放到移动硬盘或网盘目录里随身携带。

十一、自动更新

应用启动时会自动检查新版本，之后每 6 小时以及每次切回 LUMEN 窗口时也会静默再查一次

（距上次检查不足 1 小时则跳过，不会频繁联网）。发现更新会在右下角弹出提示，

点「立即下载」→「重启安装」即可，无需重新下载安装包。不想一直开着应用等更新，

也可以在设置页随时手动「检查更新」。

十二、常见问题

  • PSD 没有缩略图？ PSD 需要在 Photoshop 保存时勾选「最大兼容性」才有预览图；重新保存后再导入即可。
  • AI 文件没有缩略图？ Illustrator 的 .ai 需要在保存时勾选「最大兼容性」（文件本体才会带一层

可渲染的 PDF）。勾选后导入即可看到首页预览；未勾选的老文件仍显示为格式图标，文件本身正常入库。

  • HEIC（iPhone 照片）？ 常规 HEIC 导入即出缩略图；个别变体（如带特殊编码的）可能仍解不出，

这类文件会正常入库并显示格式图标，不影响查看原图与导出。

  • 剪藏没反应？ 确认 LUMEN 应用正在运行，且没有被其他程序占用 45678 端口。
  • 数据在哪？ 素材库在 文档\EagleLike.library；配置在 %APPDATA%\eagle-like。卸载应用不会删除素材库。
