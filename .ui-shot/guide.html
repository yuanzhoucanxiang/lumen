LUMEN 拾光档案馆 · 安装使用说明

一个类 Eagle 的本地素材管理工具：收集、整理、检索你的图片/视频/字体/PSD 素材。
数据全部存在你自己电脑上，无需注册、无需联网（联网仅用于自动更新）。

一、下载与安装

  1. 打开下载页，下载最新的 Lumen-x.x.x-setup.exe（约 147MB）：

https://github.com/yuanzhoucanxiang/shiguang-materials/releases/latest

  1. 双击安装包。如果 Windows 弹出蓝色警告「已阻止启动无法识别的应用」：

点 「更多信息」→「仍要运行」（软件没有购买代码签名证书，属正常现象，放心安装）。

  1. 安装完成，桌面会出现 LUMEN 图标，双击即用。

二、第一次使用

  • 首次启动会自动创建素材库，位置在 文档\EagleLike.library（素材都存这里，别手动改里面的文件）。
  • 导入素材的六种方式：
  1. 直接把文件/文件夹拖进窗口
  2. 左上角蓝色「导入」按钮
  3. 复制图片后按 Ctrl+V 粘贴
  4. 复制图片网址后按 Ctrl+V 直接抓取网页图片入库（一次可粘多条）
  5. 用浏览器扩展剪藏网页图片（见第六节）
  6. 顶栏「截图」按钮做区域截图：窗口自动隐藏，拖框选取屏幕任意区域，松开即入库（Esc 取消）

四、整理素材

  • 评分：悬停卡片点星星，或选中后按键盘 1–5
  • 打标签：选中图片，在右侧详情面板添加；多选可批量打标签/批量评分
  • 文件夹：侧栏右键 → 新建文件夹/子文件夹，把图拖进去即可（可多选批量拖）
  • 智能文件夹：按条件自动聚合（如「4星以上 + 横图 + 近30天」），条件随时可改
  • 标签分组与颜色：右键标签可设颜色、移动到分组，让标签区井井有条
  • 批注/裁剪：右键图片 →「批注 / 裁剪」（画笔/矩形/箭头/文字/裁剪，15 步撤销）
  • 回收站：删除先进回收站，可恢复；Ctrl+Z 撤销删除；30 天前内容自动清理
  • 导出：右键 →「导出到文件夹…」或「打包为 ZIP…」
  • 备份与恢复：设置 →「备份」可查看数据库快照（保留 3 代）并一键恢复，恢复前自动保存当前库现场，防误操作
  • AI 智能处理：设置 →「AI 智能处理」填 Base URL / 模型 / API Key（支持智谱、通义、Ollama 等），选中素材后一键批量改名+打标签，还可用自然语言语义搜图

五、白板工作台

视觉化整理参考：做情绪板、分镜参考，或把素材组织成画面关系。

  • 上板：把素材卡片拖进画布，或点卡片「发送到白板」；图片按原始比例落位（长边封顶 1280px、不放大），大图一开始就是清晰原图。
  • 导航：空格+拖动平移；滚轮缩放；F 或双击空白适配全部；0 复位。白板会记住上次的缩放与位置，重开自动恢复。
  • 浮动置顶：点「白板浮动置顶」把当前白板做成独立小窗贴在屏幕最上层（参考作画时放旁边）；标题条可拖，「最小化」折叠成标题条窄条，「展开」还原，「归位」贴回屏幕右上角；重开保持位置、尺寸与折叠状态。
  • 工具与交付：顶栏可选手绘/箭头/形状/文字；右键可对齐、排列、等距分布；导出 .lumenboard（可继续编辑）或 SVG（交付用）。

六、浏览器剪藏（LUMEN Clip）

在网页上看到好图，一键收进库里：

  1. 打开 Chrome → 地址栏输入 chrome://extensions → 右上角打开开发者模式
  2. 点「加载已解压的扩展程序」，选择发给您的 browser-extension 文件夹
  3. 保持 LUMEN 应用在运行，然后：
  • 点扩展图标 →「剪藏本页图片」批量收图（可按尺寸/格式过滤）
  • 「区域截图」框选网页局部；「整页长截图」自动滚动拼接
  • 或在图片上右键 → 剪藏图片到 LUMEN

七、自动整理（监控文件夹）

设置（左下角 ⚙）→「监控文件夹」添加目录，支持多个、含子目录。

之后这些文件夹里新出现的图片/视频会自动导入素材库——

配合下载目录使用，下载即入库。

八、多个素材库

侧栏底部可切换/新建素材库（比如「工作图库」和「个人图库」分开）。

每个库是一个独立文件夹，也可以放到移动硬盘或网盘目录里随身携带。

十、自动更新

应用启动时会自动检查新版本。发现更新会在右下角弹出提示，

点「立即下载」→「重启安装」即可，无需重新下载安装包。

十一、常见问题

  • PSD 没有缩略图？ PSD 需要在 Photoshop 保存时勾选「最大兼容性」才有预览图；重新保存后再导入即可。
  • AI/HEIC 格式？ 暂不支持生成缩略图，会显示为格式图标，文件本身正常入库。
  • 剪藏没反应？ 确认 LUMEN 应用正在运行，且没有被其他程序占用 45678 端口。
  • 数据在哪？ 素材库在 文档\EagleLike.library；配置在 %APPDATA%\eagle-like。卸载应用不会删除素材库。
